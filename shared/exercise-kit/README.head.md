# デバッグ演習:練習用ECショップ

このリポジトリは、デバッグ演習用の小さなECサイトです。`チケット/` に、利用者や社内の関係者から寄せられた不具合の報告が入っています。報告をもとに原因を特定し、修正してください。

## 演習の進め方

1. `チケット/` から担当するチケットを一つ選ぶ。
2. `調査ログ/テンプレート.md` をコピーして、`調査ログ/チケット-◯.md` を作る。
3. 調査の過程を調査ログに書きながら、原因を特定する。推測ではなく、確認した事実をもとに仮説を立て、検証してください。
4. 修正したら、直ったことを確かめる方法も含めて調査ログにまとめ、ブランチを切ってコミットする。

AIの利用範囲は、指導担当から伝えられたルールに従ってください。AIを使った場合は、何を聞き、どう検証したかを調査ログに残してください。

## 起動方法

Docker と Docker Compose が必要です。

```bash
docker compose up --build
```

初回は数百万件の注文データを投入するため、起動まで数分かかります。`db` コンテナのログが落ち着き、`backend` が起動したら準備完了です。

| 画面・サービス | URL |
|---|---|
| ショップ画面 | http://localhost:5173 |
| バックエンドAPI | http://localhost:8080/api/products など |
| 決済代行モックの処理記録 | http://localhost:4010/charges |
| PostgreSQL | localhost:5432(ユーザー `app` / パスワード `app` / DB `shop`) |

画面右上で、ログイン中のユーザー(田中さん / 佐藤さん)を切り替えられます。

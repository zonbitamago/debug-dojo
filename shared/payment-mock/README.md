# 決済代行API 仕様(モック)

外部の決済代行サービスを模したモックです。演習では「自社では変更できない外部サービス」として扱ってください。

## POST /charge

リクエスト

```json
{ "orderNumber": "ORD-10000001", "amount": 12800 }
```

レスポンス

| ステータス | 内容 |
|---|---|
| 200 | 承認。`{ "status": "approved", "chargeId": "ch_..." }` |
| 402 | 与信上限超過(5万円を超える決済)。`{ "status": "declined", "code": "limit_exceeded" }` |
| 400 | リクエスト不正 |

応答時間の目安

- 1万円以下の決済:150ms程度
- 1万円を超える決済:追加認証を行うため1.5秒程度

## GET /charges

直近100件の決済処理の記録を返します(決済代行会社の管理画面に相当)。
ブラウザで http://localhost:4010/charges を開くと確認できます。
